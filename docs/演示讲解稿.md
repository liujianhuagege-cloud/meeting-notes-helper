# 会纪通 · 5 分钟演示讲解稿（录屏按此顺序）

建议使用 Windows 自带「Xbox Game Bar」或「剪映/腾讯会议共享」录制浏览器窗口，控制在 4.5–5.5 分钟。上传网盘后把链接写进报告附录 B。

## 0:00–0:30 选题与问题

打开报告封面或本 README，说明：实训每人一题，我做的是会议录音/转写智能整理，解决会后待办丢失。强调不需要 GPU。

## 0:30–1:00 运行环境

终端执行：

```powershell
cd C:\Users\Administrator\meeting-minutes-ai
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

展示浏览器 http://localhost:8501。

## 1:00–2:30 主功能

1. 上传 `data/samples/sample_transcript.txt`（或把内容粘贴进文本框）。
2. 关闭或打开侧边栏「优先调用大模型」（无 Key 时关闭更稳）。
3. 点击「生成纪要」。
4. 指着摘要、决策、待办表（负责人/截止）讲：这是执行清单。
5. 下载 Word，用 Word 打开 10 秒证明可分发。

## 2:30–3:30 技术路线

打开 `src/analyzer.py` 或报告图1-1：双引擎——有 Key 走大模型 JSON，没有则 TF-IDF + 线索词。提一句测试：`pytest -q` 通过。

## 3:30–4:30 测试与不足

对照样例：规则兜底、有效会话口径被抽到。主动说不足：关键词容易变成人名，没有说话人分离。体现“问题应对”。

## 4:30–5:00 收尾

展示 README 运行说明、报告自评 88 分构成。结束语：源代码见 Git 链接，谢谢老师。
