```powershell

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

.\.venv\Scripts\python.exe -m pytest -q
```

## 2:30-3:30 技术路线：双引擎一句话讲透（切 `src/analyzer.py`）

【操作】切到 `src/analyzer.py`，滚到 `analyze()` 函数，顺手 `pytest -q` 跑一下（提前跑通，录屏只展示绿色 passed）。
【话术】
> “技术上我是双引擎，保证弱网、无 Key 也可用：有 Key 时走大模型，用 `src/prompts.py` 约束它只输出 JSON，再解析成标题、摘要、待办；没 Key 时自动降级到本地 TF-IDF + 线索词——比如看到‘负责、截止、下周’就判为待办，看到‘决定、拍板、同意’就判为决策。入口就是这个 `analyze()` 函数，50行，失败自动 fallback，所以刚才关掉大模型也能出结果。单元测试 `tests/test_analyzer.py` 已全过。”
