# 《专业综合实训》项目报告草稿（请另存为 Word 后按班级模板排版）

**题目：** 会纪通——基于 Python 的会议录音智能整理系统  
**开发语言：** Python  
**主要库：** Streamlit、Scikit-learn、OpenAI SDK、python-docx（可选 OpenAI-Whisper）

---

## 1 问题定义

线下会议结束后，纪要依赖人工回忆，容易漏待办、对不齐责任人。本项目面向学生/小团队，提供**轻量化、软件为主**的工具：输入录音或转写，输出结构化纪要（摘要、议题、决策、待办）。

创新点：同一套界面同时支持 **本地抽取（无 Key）** 与 **大模型 JSON 纪要**，降低硬件与 API 门槛；待办导出 Word，便于直接转发。

## 2 系统设计

- **输入层：** 文本粘贴 / txt / 音频  
- **识别层：** Whisper（可选）或已有转写  
- **分析层：** 优先 LLM；失败或无 Key 时 TF-IDF 摘要 + 规则待办  
- **输出层：** 网页展示 + Markdown + docx  

（可在 Word 中补一张数据流图：上传 → 转写 → analyze() → 展示/下载）

## 3 技术实现

- `src/analyzer.py`：`analyze_local` 用句向量 TF-IDF 选中心句；用关键词规则抽「需要/负责/截止」类待办。  
- `analyze_with_llm`：OpenAI 兼容 Chat Completions，强制 JSON。  
- `app.py`：Streamlit 双栏布局，侧边栏开关「优先调用大模型」。  
- 不依赖 GPU；模型调用走云端 API。

## 4 测试与改进

- 使用 `data/samples/sample_transcript.txt` 作为标准样例。  
- `pytest` 校验：能抽出摘要、待办与决策句。  
- 改进记录（请按实际填写）：例如增加负责人正则、LLM 失败自动回退本地引擎。

完成了从选题、设计、编码到可演示交付的闭环。后续可加说话人分离、日历 ICS 导出、多文件批量处理。
